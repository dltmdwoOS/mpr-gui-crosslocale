# 분석 규칙 초안 (2026-11-12)

상태: **초안. 모든 항목 미정.** 권장안은 제안이며 팀 확인 후 고정한다.

이 규칙은 Qwen3-VL-8B와 InternVL3.5-8B 결과를 본 뒤에 작성했다. 따라서 이 두 모델에 대해서는 사전 등록이 아니며, 원고에도 그렇게 밝힌다. 사전 규칙으로 기능하는 범위는 앞으로 추가할 모델(InternVL2.5-8B 재실행, Gemma-4-E4B 등)이다.

## 1. 주 지표

| 선택지 | 내용 |
|---|---|
| **권장: 생성 답 일치 (`generation_correct`)** | MPR-GUI와 같은 채점 방식. 레이블 확률 채점(`scoring_correct`)은 민감도 분석으로 함께 보고 |
| 레이블 확률 | thinking·출력 형식 문제에 덜 민감하지만 선행연구와 비교가 어긋남 |

근거: InternVL3.5 6×6에서 생성–점수 불일치는 79,020행 중 0건이다(`results/internvl35_validation.json`). R_stem/R_opts는 두 모델 모두 두 지표의 결과가 같다. Qwen3 6×6의 불일치율은 확인이 필요하다.

모델별로 두 지표의 일치율과 파싱 실패 수를 표로 보고한다. InternVL3.5 6×6의 파싱 실패는 41건이다.

## 2. 태국어 처리

기존 문서(2026-11-07 모델 후보 문서)의 기준은 "TH→TH 일치 조건의 정답률이 우연 수준(25%)에 가까우면 제외"였다. 이 기준은 현재 두 모델에서 작동하지 않는다.

| | Qwen3 | InternVL3.5 |
|---|---|---|
| TH→TH 6×6 전체 정답률 | 79.0% | 70.1% |
| TH→TH REL 정답률 (EN→EN 대비) | 69.4% (83.3%) | 46.7% (86.1%) |
| 위치 지정 R 조건, 태국어 화면 명중률 | 93.2% | 40.9% (영어 화면 96.0%) |
| 위치 지정 태국어 화면 R−O | +50.4%p | +3.0%p [−1.9, 7.8] |

InternVL3.5의 태국어 화면 위치 지정은 네 조건 모두 38–41%다. referent가 이미 태국어인 R 조건에서도 낮으므로 언어 불일치보다 글자 인식 실패로 보는 것이 자연스럽다. 다만 이것은 해석이며 원인을 검증하지는 않았다.

| 선택지 | 내용 | 위험 |
|---|---|---|
| **권장: 제외하지 않고 둘 다 보고** | 모든 모델에서 4언어 결과와 태국어 제외 결과를 함께 보고한다. 아래 읽기 점검은 해석 표시용으로만 쓴다 | 표가 늘어남 |
| 읽기 점검에 걸린 모델·과제만 태국어 제외 | 예: 위치 지정 R 조건 태국어 화면 명중률이 영어 화면의 60% 미만이면 제외 | 문턱값을 결과를 본 뒤 정했다는 비판 |
| 처음부터 3언어(en·zh·ru)만 주 분석 | 모든 모델에 같은 규칙 | Qwen3의 태국어 효과(+50.4%p)처럼 흥미로운 결과를 부록으로 내림 |

읽기 점검 후보(해석 표시용):
- 객관식: TH→TH REL 정답률 / EN→EN REL 정답률
- 위치 지정: 태국어 화면 R 조건 명중률 / 영어 화면 R 조건 명중률

참고: 태국어를 빼면 Qwen3의 6×6 일치 보너스는 +1.71 → +0.84%p로 줄었다. InternVL3.5는 +1.38 [0.91, 1.85] → +1.46 [1.03, 1.90]%p로 유지됐다. 태국어 제외 여부가 모델마다 결론에 다르게 작용하므로 둘 다 보고하는 쪽이 안전하다.

## 3. 주 대비와 다중비교

| 묶음 | 주 대비 | 보정 |
|---|---|---|
| O/R/C/F (의존 문항) | R−O, C−O, F−C, F−R | 모델별 Holm (4개) |
| R_stem/R_opts | 질문 효과 S, 선택지 효과 P, 상호작용 I | 모델별 Holm (3개, 현재 분석과 동일) |
| 위치 지정 | R−O, C−O, F−R | 모델별 Holm (3개) — 미정 |
| 언어 방향·화면 언어별 분해 | 전부 | 보정 없음, "탐색적"으로 표시 |

다중비교 보정을 주 결과에 쓸지는 미정이다. 현재 결과에서는 Holm 보정으로 판정이 바뀌는 칸이 없다. 예외는 InternVL3.5 선택지 효과 P이며, 이것은 보정 전에도 유의하지 않았다.

## 4. 모델 간 주장

- 모델 간 절대 점수는 비교하지 않는다. 주장은 모델 안의 조건 차이로만 한다.
- "모델 전반에서 일관된다"는 주장은 각 모델 추정치와 부호 일치로만 한다. 합동 검정을 할지는 미정이다.
- 계보 표기: Qwen3-VL과 InternVL3.5는 같은 Qwen3 언어 모델을 쓴다. 비Qwen 모델이 들어오기 전에는 "여러 계보"라고 쓰지 않는다.

## 5. 위치 지정 실행 조건 (새 모델에 적용)

현재 두 모델의 위치 지정 입력에는 시스템 프롬프트 내용이 없다. Qwen3에는 시스템 블록 자체가 없고, InternVL3.5에는 빈 시스템 블록이 들어갔다(raw `rendered_prompt` 확인). 객관식은 영어 고정 시스템 프롬프트를 쓰므로 두 과제의 입력 조건이 다르다.

- **권장:** 새 모델의 위치 지정도 시스템 프롬프트를 비운 채 실행한다. 이렇게 하면 기존 두 모델과 비교할 수 있다. InternVL2.5는 기본 중국어 시스템 문구가 들어가므로 InternVL3.5처럼 빈 문구로 덮어쓴다.
- Methods에 과제별 시스템 프롬프트 차이를 밝힌다.

## 6. 새 모델 포함 기준 (본실행 전 점검)

| 점검 | 통과 기준(제안) |
|---|---|
| 객관식 10문항 | 첫 토큰이 A–D 레이블, thinking 꺼짐, 시스템 프롬프트가 실제 입력에 포함 |
| 위치 지정 파일럿 28응답 | 유효 좌표 비율 95% 이상. 미달이면 해당 모델은 위치 지정에서 제외하고 객관식만 실행 |
| 시각 토큰 | 2,048 이하. 모델의 최대치가 더 낮으면 그 값을 보고 (Gemma-4-E4B 1,120) |
| 실행 계약 | 배치 1, bf16, revision 고정 |

문턱값(95%)은 제안이며 미정이다.

## 7. 위치 지정–객관식 연결 분석 (두 모델 공통으로 고정)

- 문항 단위 상관: 위치 지정 R−O와 객관식 R−O의 Pearson·Spearman, 문항 bootstrap 10,000회
- 쌍 단위 교정: "O에서 객관식을 틀렸고, R에서 위치를 맞힌 쌍" 중 위치가 0→1로 고쳐진 쌍과 원래 맞힌 쌍의 객관식 교정률 차이
  - 문항 bootstrap 5,000회
  - 언어 보정 GLMM `mR ~ gfix + gui + qry + (1|item)`, LRT
- 주장 범위: 연관성. 매개효과나 개별 오류의 원인으로 쓰지 않는다.
