# 분석 규칙 v1 (고정 후보, 2026-11-14)

상태: **고정 후보. 팀 확인 전.** 확인되면 이 파일을 읽기 전용으로 바꾸고 sha256을 `분석규칙_v1.FROZEN.txt`에 적는다. 원래 초안 `분석규칙_초안.md`(2026-11-12)는 그대로 둔다.

## 0. 적용 범위와 시점

- 이 규칙은 Qwen3-VL-8B, InternVL3.5-8B 결과를 본 뒤에 썼다. 두 8B 모델에 대해서는 사전 규칙이 아니며 원고에도 그렇게 밝힌다.
- 사전 규칙으로 기능하는 대상은 고정 시점에 결과를 아직 열지 않은 모델이다. Qwen3-VL-4B, InternVL3.5-4B, UI-TARS-1.5-7B, MiniCPM-V-4.5의 REL O/R/C/F, 실험 A O/T/R, 6×6이 여기에 해당한다.
- 서버 큐가 결과를 만드는 것은 막지 않는다. 고정 전에는 결과 묶음을 내려받기만 하고 정확도를 계산하지 않는다. 큐 진행 기록(`QUEUE_STATUS`)의 smoke 정확도 한 줄은 이미 보였다. Qwen3-VL-4B는 smoke 기준 REL 0.54, 실험 A 0.68이다(80회, 108회). 이 사실을 기록에 남긴다.
- 실험 A의 진단 분석(`diag_expA.py`)은 새 모델에 같은 코드로 돌리되 "descriptive"로 표시한다. 확인 검정은 InternVL3.5-8B 한 번으로 끝났다.

## 1. 주 지표

- 주 지표는 생성 답 일치(`generation_correct`)다. MPR-GUI와 같은 채점이다.
- 레이블 확률 채점(`scoring_correct`)은 민감도 분석으로 함께 보고한다.
- 모델마다 두 지표의 일치율과 파싱 실패 수를 표로 보고한다.
- 생성 파싱 실패가 그 모델 행의 2%를 넘으면 그 모델은 두 지표의 결론이 같을 때만 본문에 쓰고, 다르면 부록으로 보내고 그 사실을 밝힌다.

## 2. 태국어

- 어떤 모델도 태국어를 빼지 않는다. 모든 분석에서 4언어 결과와 태국어 제외 결과를 나란히 보고한다.
- 주 판정(Holm 검정의 성립 여부)은 4언어 결과로 한다. 태국어 제외 결과로 판정이 바뀌면 그 사실을 본문에 적는다.
- 읽기 지표는 해석 표시용으로만 쓰고 제외 기준으로 쓰지 않는다. 새 GPU 실행 없이 이미 도는 실험에서 계산한다.
  - REL R 조건 정답률: 태국어 화면 ÷ 영어 화면
  - 6×6이 있는 모델은 TH→TH 정답률 ÷ EN→EN 정답률
- 읽기 지표가 0.7 미만인 모델은 표에 "태국어 화면 읽기 약함"으로 표시한다. 그 모델의 태국어 결과는 언어 효과가 아니라 읽기 실패와 섞였을 수 있다고 적는다.
  - 0.7은 InternVL3.5-8B(REL 46.7/86.1 = 0.54)와 Qwen3-VL-8B(69.4/83.3 = 0.83)를 본 뒤 그 사이로 정한 값이다. 사후 문턱이라고 밝힌다.

## 3. 주 대비와 다중비교

| 묶음 | 주 대비 | 보정 |
| --- | --- | --- |
| REL O/R/C/F | R−O, C−O, F−C, F−R | 모델별 Holm 4개 |
| 실험 A O/T/R | T−O, R−T (R−O는 보고만) | 모델별 Holm 2개 (사전 계획과 같음) |
| 6×6 | 일치 보너스(같은 언어 쌍 − 다른 언어 쌍) | 한 개라 보정 없음 |
| 언어 방향·화면 언어별 분해, 크기 비교 | 전부 | 보정 없음, "탐색적" 표시 |

- 신뢰구간은 문항 단위 bootstrap 10,000회다. 앱 단위 bootstrap은 민감도 분석으로 부록에 둔다.
- 실험 A의 주 분석 집합은 1,895쌍이다(`rel::5/forest_9.jpg::zh::ru` 제외, 사전 계획과 같음).

## 4. 모델 간 주장

- 모델 간 절대 점수는 비교하지 않는다. 주장은 모델 안의 조건 차이로만 한다.
- "모델 전반에서 일관된다"는 각 모델의 추정치 부호와 Holm 판정을 나란히 보여 주는 것으로만 말한다. 합동 검정은 하지 않는다. 예: "6개 모델 중 5개에서 T−O가 음수이고 그중 4개에서 유의".
- 크기 축(4B 대 8B)은 같은 계열 안의 두 점이라 크기 경향을 주장하지 않는다. 표로 보여 주고 "크기에 따라 달라지는지는 두 점으로 판단할 수 없다"고 적는다.
- 계보 표기: 이번 큐의 모델은 모두 Qwen 계열 언어 모델 위에 있다. Qwen3-VL 4B/8B, InternVL3.5 4B/8B, MiniCPM-V-4.5는 Qwen3이고, UI-TARS-1.5-7B는 Qwen2.5-VL 기반이다(확인 필요). 따라서 "여러 언어 모델 계열"이라고 쓰지 않는다. 비전 인코더와 학습 데이터는 다르다고만 쓴다.

## 5. 새 모델 포함 기준

- 큐 게이트(모든 행 성공, 파싱 실패 기준, 라벨 쏠림, A–D 확률 질량)를 통과한 모델만 본문 표에 넣는다. 게이트에서 멈춘 모델은 부록에 이유와 함께 적는다.
- 시각 토큰 예산은 모델마다 다르다. MiniCPM-V-4.5는 576~640토큰이고, Qwen3·InternVL은 최대 약 2,048~2,304토큰이다. Methods에 모델별 값을 적는다. Qwen3 계열 어댑터는 `visual_token_count`를 기록하지 않으므로 `prompt_token_count`로 대신 보고한다.
- 배치 크기: 새 모델은 전부 배치 1이다. Qwen3-VL-8B의 실험 A는 배치 3, 6×6은 배치 4였다. Qwen3-VL-8B를 배치 1로 다시 돌린 672회와의 답 일치율은 98.66%였다(663/672). Methods에 적는다.
