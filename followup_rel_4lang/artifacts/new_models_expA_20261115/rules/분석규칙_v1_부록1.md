# 분석 규칙 v1 부록 1 (2026-11-14)

규칙 7절에 따른 사후 변경이다. 원고에는 아래 항목을 사후 변경으로 밝힌다.

## 이 부록을 쓸 때 이미 열어 본 결과

- 8B 두 모델(Qwen3-VL-8B, InternVL3.5-8B)의 REL, 실험 A, 6×6 결과 전부
- Qwen3-VL-4B의 REL과 실험 A 결과 전부(고정 규칙으로 분석한 `analysis_newmodels_20261114/qwen3_vl_4b/`)
- 그 밖의 새 모델 결과는 열지 않았다.

## 1. "태국어 제외"의 정의 (REL, 실험 A)

- 규칙 2절은 태국어 제외 결과를 나란히 보고한다고만 적었고, 무엇을 빼는지는 정하지 않았다.
- 정한 것: 본문 표의 "태국어 제외" 값은 질문 언어나 화면 언어 중 하나라도 태국어인 쌍을 모두 뺀 값(noTH_both)이다. 6×6의 5×5 정의와 맞춘다.
- 화면만 태국어인 쌍을 뺀 값(noTH_screen)도 부록 표에 함께 보고한다.
- 정한 이유와 시점: Qwen3-VL-4B에서 REL C−O의 유의 여부가 두 정의 사이에서 갈렸다(noTH_screen 유의하지 않음, noTH_both −2.8, Holm 0.0012). 이 차이를 본 뒤 정했다.
- 주 판정은 규칙 2절대로 전체 언어 결과로 한다. 이 부록은 주 판정을 바꾸지 않는다.

## 2. 태국어 읽기 지표 (a)의 계산 범위

- 규칙 2절은 "(a) REL R 조건 정답률, 전체 문항"이라고 적었지만, 같은 절에 인용한 8B 값(0.95/0.60)은 원문 이슈가 없는 언어 간 행만으로 계산한 값이었다(재계산 0.954/0.603).
- 정한 것: (a)는 8B 인용값을 재현하는 범위(원문 이슈가 없는 언어 간 행, eligible_only)로 계산한다. 전체 행으로 계산한 값(all_rows)도 함께 적는다.
- Qwen3-VL-4B: eligible_only 0.917, all_rows 0.888. 어느 쪽이든 0.7 이상이라 표시는 없다.
- 이 범위는 4B 결과를 본 뒤 작업 중에 맞췄다.

## 3. 부트스트랩 p 계산식

- 새 모델 분석은 p = (1 + 반대 부호 개수) / (B + 1), B = 10,000을 쓴다.
- 이전 8B 분석 일부(t1_holm)는 개수 / B를 썼다. 두 식의 차이는 최대 약 0.0001이고 판정에는 영향이 없다(확인 필요: 8B 값을 새 식으로 다시 계산해 대조).

## 4. 결과 보관

- 모든 분석 변형(전체 언어, noTH_screen, noTH_both, 읽기 지표 두 범위, 생성 채점과 레이블 확률 채점)을 결과 파일에 함께 저장한다. 본문에 쓰지 않는 값도 지우지 않는다.
- 서버 결과는 로컬로 내려받아 sha256을 확인한 뒤에만 서버에서 지운다.

## 5. 한계로 적을 것

- Qwen3-VL-4B에서 생성 답 채점과 레이블 확률 채점이 100% 일치했다. 레이블 확률 채점은 독립된 민감도 확인이 아니다. 원고에 "민감도 분석으로 확인했다"고 쓰지 않는다.
