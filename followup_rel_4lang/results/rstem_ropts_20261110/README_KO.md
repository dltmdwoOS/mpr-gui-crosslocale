# REL R_stem / R_opts 실험 결과 (Qwen3-VL-8B, InternVL3.5-8B)

2026-11-10 정리. RTX 4090 한 장, 158문항 × 불일치 언어쌍 12개 = 1,896쌍, 조건 4개, 모델당 7,584회 추론.

## 무엇을 바꿨나

질문 틀은 질문 언어로 두고, 화면 요소 이름만 바꿨다.

| 조건 | 질문 본문의 기준 요소 이름 | A–D 보기의 요소 이름 |
| --- | --- | --- |
| O | 질문 언어 | 질문 언어 |
| R_stem | 화면 언어 | 질문 언어 |
| R_opts | 질문 언어 | 화면 언어 |
| R | 화면 언어 | 화면 언어 |

본문 효과 S = [(R_stem−O)+(R−R_opts)]/2, 보기 효과 P = [(R_opts−O)+(R−R_stem)]/2, 상호작용 I = R−R_stem−R_opts+O. 문항 단위 bootstrap 10,000회(seed 20261109) 95% 구간, S·P·I에 Holm 보정. 분석 방법은 결과를 보기 전에 [Qwen3 계획](../../analysis/rstem_ropts/ANALYSIS_PLAN_KO.md)과 [InternVL3.5 계획](../../analysis/rstem_ropts/ANALYSIS_PLAN_INTERNVL_KO.md)에 고정했다.

## 읽는 법

- 두 모델 모두 질문 본문의 기준 요소 이름을 화면 표기와 맞추면 정답률이 올랐다.
- 보기 효과는 Qwen3에서 0과 구별되고, InternVL3.5에서는 주 분석 구간이 0을 포함한다(GLMM에서는 유의). InternVL3.5는 "작고 불확실하다"로 쓴다.
- "본문 효과가 보기 효과보다 크다"는 Qwen3에서만 사전 기준(S−P 구간이 0을 넘음)을 통과했다. InternVL3.5도 방향은 같다.
- 양수 I는 "함께 맞추면 더 좋아진다"로 해석하지 않는다. 한 질문 안에 두 언어가 섞인 R_stem·R_opts가 손해를 보면 I가 커지기 때문이다(`ANALYSIS_PLAN_KO.md` 끝의 2026-11-10 정정).
- 본문 효과가 "요소를 찾게 되어 맞혔다"는 인과를 보여 주지는 않는다.

## 화면 언어별 (탐색, 결론 근거 아님)

태국어 화면에서 두 모델이 반대로 나왔다. Qwen3는 R−O +33.97%p(S +20.04, P +13.92)로 가장 컸고, InternVL3.5는 R−O −4.01%p, S −3.80%p[−6.96, −0.63]였다. 영어·중국어·러시아어 화면에서는 InternVL3.5도 S가 +3.9~+7.4%p로 Qwen3와 같은 방향이다. 세부 값은 `*/analysis_out/by_gui.csv`.

- 두 모델 모두 7,584행 성공, 답 파싱 실패 0건.
- 다시 돌린 O·R 답이 기존 실행과 같은 비율: Qwen3 99.53%(11월 7일 대비, 배치 4), InternVL3.5 100%(11월 9일 대비, 배치 1).
