# PP-OCR V-D-S와 V-D-H 개발 평가

8B와 4B 모두 Screen, Selection, Internal을 마쳤다. 같은 158문항·1,895쌍에서 **8B V-D-H가 78.26%로 가장 높았다.** 4B에서도 V-D-H가 73.98%로 가장 높았고, V-D-S와 기존 L-D-S 대비 차이의 95% 신뢰구간은 모두 0을 포함했다. RTX 4090에서는 **8B V-D-H를 먼저 재검증**하고, 보기 원문을 유지하는 V-D-S와 원본 O를 같은 장비에서 비교한다.

세 편집 조건은 PP-OCRv5 inventory를 공유한다. L-D-S는 고정 Qwen3-8B가 편집하고, V-D-S와 V-D-H는 최종 풀이에 쓰는 모델로 stem 참조를 추출하고 정렬한다. S는 보기를 원문으로 두고 H는 네 보기를 GUI 언어로 번역한다. Screen pilot 48쌍과 Selection에서 사전에 제외한 1쌍은 주 집계에서 빠진다. 표의 시간은 OCR, 추출, 편집·repair, 최종 풀이의 실행 구간 합이며 모델 적재와 실행 준비 시간은 별도다. 재사용한 배치에는 원래 측정 시간을 포함했다. 이번 Selection·Internal 확장은 약 3시간 36분 걸렸으며 최종 예측 6,624행 중 2,343행을 재사용했다. 원시 예측의 pair ID, 파싱된 답, 정답 수를 다시 대조해 집계와 일치함을 확인했다.

8B에서 H는 S보다 **10.68분 더 걸렸고 정답이 50개 늘었다**. 4B에서는 **20.08분 더 걸렸고 24개 늘었다**. 두 모델 모두 H의 최종 풀이 시간은 짧았고 편집·repair에서 시간이 더 들었다. 같은 stem으로 나온 쌍에서는 8B 1,776쌍 중 H가 53개, 4B 1,457쌍 중 H가 18개 더 맞혔다. Stem도 바뀐 쌍에서는 각각 3개 줄고 6개 늘었다. 동일 stem 부분집합은 변환 후 정한 범위이므로 관찰치로 해석한다.

두 모델 모두 H의 순증가는 태국어 GUI에 집중됐다. 태국어 GUI 밖에서는 H의 정답이 8B에서 17개, 4B에서 32개 줄었다. 4090에서도 전체 점수와 GUI 언어별 회복·회귀를 함께 확인한다. 현재 개발 결과만으로 언어별 적용 규칙을 정하기에는 표본이 제한적이다.

V-D-S와 V-D-H가 공유한 source span 추출의 exact F1은 8B 94.63%, 4B 76.39%, 기존 고정 LM 91.95%였다. H에서 편집의 일부 이상이 원문으로 돌아간 쌍은 8B 14개, 4B 245개였다. 이 중 4B는 241쌍의 stem에서 fallback이 일어났다. 이 수치는 편집 단계의 구조적 결과이며 보기 번역이 의미를 보존했는지는 별도 검수가 필요하다.

B200에서 8B V-D-H는 4B V-D-H보다 같은 문항을 81개 더 맞히고 측정된 총 계산시간도 약 4.8분 짧았다. 4090에서는 8B부터 메모리와 실제 초/pair를 확인하고, 4B는 메모리 장점이 필요할 때 비교한다. [4090 실행 안내](PPOCR_EDITOR_MATRIX_4090_PILOT_KO.md)
