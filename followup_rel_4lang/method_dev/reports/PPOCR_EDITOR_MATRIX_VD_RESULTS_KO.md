# PP-OCR V-D-S와 V-D-H 개발 평가

8B는 전체 158문항·1,895쌍에서 **V-D-H 78.26%**, **V-D-S 75.62%**, 기존 **L-D-S 74.93%**였다. 정확도를 우선하는 RTX 4090 재검증의 첫 후보는 **8B V-D-H**다. 보기 원문을 유지하는 V-D-S를 비교 조건으로 같이 가져간다. 4B는 이 기록 시점에 Screen과 Selection 479쌍을 완료했으며 Internal을 실행 중이었다.

모든 조건은 PP-OCRv5 inventory를 공유한다. L-D-S는 고정 Qwen3-8B가 편집하고, V-D-S와 V-D-H는 최종 풀이에 쓰는 모델로 stem 참조를 추출하고 정렬한다. S는 보기를 원문으로 두고 H는 네 보기를 GUI 언어로 번역한다. Screen pilot 48쌍과 Selection에서 사전에 제외한 1쌍은 주 집계에서 빠진다. 표의 시간은 OCR, 추출, 편집·repair, 최종 풀이의 실행 구간 합이며 모델 적재와 실행 준비 시간은 별도다. 재사용한 배치에는 원래 측정 시간을 포함했다.

신뢰구간은 같은 pair끼리 비교하고 semantic item 단위로 10,000회 bootstrap한 탐색 결과다. 반복 관찰한 개발 집합이므로 최종 일반화 판단에는 독립 데이터가 필요하다.

8B에서 H는 S보다 **10.68분 더 걸렸고 정답이 50개 늘었다**. 편집·repair는 36.85분에서 52.23분으로 늘었으며, 최종 풀이 시간은 22.42분에서 17.71분이었다. 같은 stem으로 나온 1,776쌍에서는 H가 53개 더 맞혔고, stem도 바뀐 119쌍에서는 3개 덜 맞혔다. 동일 stem 부분집합은 변환 후 정한 범위이므로 관찰치로 해석한다.

태국어 GUI 밖에서는 H의 정답이 17개 줄었다. 4090에서 결과를 다시 비교할 때 전체 점수와 GUI 언어별 회복·회귀를 함께 확인한다. 현재 개발 결과만으로 언어별 적용 규칙을 정하기에는 표본이 제한적이다. 8B V-D-S와 V-D-H는 추출을 공유하며 source span F1은 94.63%, 기존 고정 LM은 91.95%였다. H에서 편집 일부를 원문으로 되돌린 쌍은 14개였다. 넷 중 어느 보기의 번역이 문제 의미를 바꿨는지는 별도 사례 검수가 필요하다.

기록은 [수치 스냅샷](../artifacts/ppocr_editor_matrix_vd_snapshot.json)에 있다. 완료된 집합별 원시 예측의 SHA-256, 두 모델의 집계 범위, 언어별 성능, repair·시간·추출 진단을 담았다. 스냅샷 생성은 `.venv/bin/python followup_rel_4lang/method_dev/scripts/snapshot_editor_matrix_vd.py`로 다시 할 수 있다. 4090에서 재검증하는 절차는 [4090 실행 안내](PPOCR_EDITOR_MATRIX_4090_PILOT_KO.md)를 따른다.
