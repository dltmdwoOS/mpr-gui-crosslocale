## REL O/R/C/F

O는 문맥·기준 표현을 source 언어로 유지한다. R은 기준 표현만 GUI 언어로,
C는 문맥만 GUI 언어로, F는 둘 다 GUI 언어로 바꾼 조건이다.
알려진 원본 문제 400행도 추론·보존했으나, 기존 규칙에 따라 주 분석에서 제외했다.
아래는 언어 불일치의 완전한 O/R/C/F 묶음에 대한 생성 답변 정답률이다.

| 텍스트 의존성 | 문항 수 / 언어쌍 묶음 수 | O | R | C | F | R−O | F−C |
|---|---:|---:|---:|---:|---:|---:|---:|
| dependent | 301 / 3,576 | 70.16% | 80.79% | 67.06% | 78.83% | +10.63%p | +11.77%p |
| independent | 63 / 716 | 79.05% | 77.93% | 78.35% | 78.63% | −1.12%p | +0.28%p |

이 실행의 dependent 집계에서는 R−O와 F−C가 양수로 관찰됐다.
independent 집계의 차이는 상대적으로 작았다. 같은 문항에서 여러 언어쌍과
예측 재사용이 발생하므로, 행 수를 독립 표본 수로 해석하지 않는다.

## Grounding main

158문항 × 12불일치 언어쌍 × 4조건이다. 관계 질문의 정답 대신 기준 요소의
좌표를 생성하고, 복원 좌표가 GT bbox 안에 있으면 적중으로 계산했다.

| 조건 | 적중 / 전체 | 적중률 | 좌표 형식 실패 |
|---|---:|---:|---:|
| O | 1,385 / 1,896 | 73.05% | 0 |
| R | 1,798 / 1,896 | 94.83% | 3 |
| C | 1,329 / 1,896 | 70.09% | 5 |
| F | 1,791 / 1,896 | 94.46% | 9 |

형식 실패를 포함한 전체 응답을 분모로 사용했다. R−O는 +21.78%p,
F−C는 +24.37%p였다. 조건 간 차이는 이 입력·모델·채점 방식에서 관찰된 값이다.
GUI 언어별 결과는 [원래 요약](artifacts/qwen3_single4090_20261107/grounding_main_orcf/summary.json)에 있다.

사용한 `main_descriptors_draft_v2.json`은 자동 추출 초안이며 `reviewed=false`다.
bbox 검수 여부와 설명의 의미적 적절성 검수는 별개이므로, 이 결과는 해당 초안에
대한 탐색 실험으로 해석한다. F의 동일 GUI 표현이 source 방향별로 반복되며,
그 응답들을 서로 독립인 문항으로 간주하지 않는다. 다른 모델 또는 메모리 형식과의
통제된 비교 실험은 이번 취합에 포함하지 않았다.

## 보존 파일과 재검산

[결과 폴더](artifacts/qwen3_single4090_20261107/)에는 다음을 보존했다.
선별 기준은 파일의 역할·중복·크기이며 정답 여부에 따른 행 선별은 하지 않았다.

- 세 전체 실험의 원시 출력 전부: 6×6 응답, REL 고유 예측·조건 행,
  grounding 예측·배치 기록을 무손실 gzip으로 저장했다. 오답·형식 실패·원본 문제 행도 포함한다.
- 요약 JSON/CSV, 전체 입력 계획·실행 계약, 배치 선택, smoke 검증,
  패키지 버전·실행 코드 commit, 전체 추론 로그와 실행 스크립트를 보존했다.
- 다운로드·준비 로그, smoke 원시 출력, 이미지, 모델 가중치와 캐시는 제외했다.
  서버의 원본 출력은 변경하지 않았다.

[MANIFEST.json](artifacts/qwen3_single4090_20261107/MANIFEST.json)에
보존 파일과 원본의 SHA-256·크기·JSONL 행 수, 설명 파일 해시 및 선별 기준이 있다.
[`metrics_and_validation.json`](artifacts/qwen3_single4090_20261107/metrics_and_validation.json)은
검증과 재계산 지표, [`grounding_format_failures.json`](artifacts/qwen3_single4090_20261107/grounding_format_failures.json)은
형식 실패 17건의 원문이다. gzip은 `gzip -dc 파일명.gz`로 원본을 덮어쓰지 않고 읽을 수 있다.

원본 출력과 데이터가 준비된 서버에서는 저장소 최상위에서 다음 명령으로 취합·검증을
다시 수행할 수 있다. 추론은 실행하지 않으며 보존 폴더의 파생 파일만 다시 작성한다.

```bash
.venv/bin/python followup_rel_4lang/collect_qwen3_single4090.py
```
