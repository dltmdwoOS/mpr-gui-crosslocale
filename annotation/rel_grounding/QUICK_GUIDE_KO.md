# 화면 위치 표시: 빠른 안내

전체 **179문항 × 4개 화면**을 각자 작업합니다. 다른 사람의 기록과 모델 답은 보지 않습니다. 새 환경이라면 먼저 [설치 및 이미지 준비](README_KO.md#설치-및-이미지-준비)를 완료하세요. 저장소 최상위에서 고유한 이름으로 실행합니다.

```bash
.venv-rel-grounding/bin/python annotation/rel_grounding/app.py --annotator 내이름 --port 8766
```

Windows PowerShell에서는 `.\.venv-rel-grounding\Scripts\python.exe annotation\rel_grounding\app.py --annotator 내이름 --port 8766`을 실행합니다. 브라우저에서 `http://127.0.0.1:8766/`을 엽니다. 두 번째 검수자는 다른 이름과 포트(예: `8767`)를 사용합니다.

1. 네 언어 화면이 한 번에 보입니다. 노란 표현이 가리키는 요소에 **대상 그리기**로 파란 상자를 그립니다. 작으면 **크게**를 누릅니다. 글자가 따로 있으면 **글자 그리기**를 쓸 수 있습니다.
2. 각 화면의 **상태**와 **종류**를 고릅니다. **가리키는 말**은 노란 표현으로 채워져 있으니, 필요하면 질문의 표현을 그대로 늘립니다. 대상을 못 찾으면 이유를 **추가 확인 · 메모**에 적습니다.
3. 영어와 같은 뜻인지 묻는 두 항목은 기본 **예**입니다. 뚜렷한 문제가 있을 때만 바꾸고 이유를 적습니다. **예**는 번역 검증 완료를 뜻하지 않습니다.
4. **저장하고 다음**을 누릅니다. 잘못 그렸다면 `Ctrl+Z`(Mac `⌘Z`) 또는 **↶ 취소**를 누릅니다. 끝나면 **내보내기**로 JSON을 백업합니다.

자세한 판정 기준과 결과 비교 명령은 [전체 안내](README_KO.md)에 있습니다.
